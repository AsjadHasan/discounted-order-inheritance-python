# discounted-order-inheritance-python
A Python OOP program demonstrating inheritance, method overriding, and super() by applying a 10% discount to an order total.
<br>
Topics Covered: 
<br>

1. Classes and Objects – Creating Order and DiscountedOrder objects.
2. Inheritance – Extending the parent Order class.
3. Method Overriding – Redefining calculate_total() in the child class.
4. super() Method – Accessing the parent class's calculation.
5. Discount Calculation – Applying a 10% discount.
6. Code Reusability – Reusing parent functionality without modifying it.
